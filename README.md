# Astros Group Sales Plan — working framework

GSCG × Houston Astros (Fall 2026). An 8-step marketing-plan framework for reimagining the Astros' large group ticket sales plan. Live: https://mateosandoval10.github.io/gscg-astros-plan/

All content is in `content.js`. To add findings, put strings in a section's `findings` array; to un-grey a step, set `active: true`.
